# growing-taste

Minimal React + Vite app. The application code lives in `src/App.jsx` and the app is bootstrapped from `src/main.jsx`.

Quick start
1. Install dependencies

```bash
npm install
```

2. Start development server (open http://localhost:5173)

```bash
npm run dev
```

Build & preview

```bash
npm run build
npm run preview
```

Notes
- I removed unused template files (CSS and example assets) to keep the repo focused on `src/App.jsx`.
